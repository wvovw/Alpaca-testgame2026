═══════════════════════════════════════════════════════════════════════════
                            更新阶段详细流程
═══════════════════════════════════════════════════════════════════════════

1. GameState.update()
   └─> 检查游戏结束条件 (Check win/loss conditions)
       ├─> 玩家基地HP ≤ 0? → 游戏结束，玩家失败
       └─> 敌方基地HP ≤ 0? → 游戏结束，玩家胜利

2. MoneyManager.update()
   └─> 每秒增加5金钱 (累加器达到1秒时执行)

3. EnemyWaveManager.update()
   ├─> 每3秒生成一个随机敌人
   └─> 每30秒提升难度等级，增强敌人属性

4. BattleArena.update()
   └─> 更新玩家角色
       ├─> 检查射程内是否有敌人
       ├─> 没有敌人？向左移动 (朝敌方基地)
       ├─> 有敌人？停止移动
       └─> 更新攻击冷却

5. EnemyAI.update()
   └─> 更新敌人角色
       ├─> 检查射程内是否有玩家角色
       ├─> 没有玩家？向右移动 (朝玩家基地)
       └─> 有玩家？停止移动

6. CombatSystem.update()
   ├─> 玩家角色攻击
   │   ├─> 寻找射程内最近的敌人
   │   ├─> 找到敌人？计算伤害并攻击
   │   └─> 没敌人但到达敌方基地？攻击基地
   └─> 敌人攻击
       ├─> 寻找射程内最近的玩家角色
       ├─> 找到角色？计算伤害并攻击
       └─> 没角色但到达玩家基地？攻击基地

7. GameState.removeDeadCharacters()
   └─> 清理所有HP ≤ 0的角色

═══════════════════════════════════════════════════════════════════════════
                            渲染阶段详细流程
═══════════════════════════════════════════════════════════════════════════

1. 清空画布 (Clear canvas with dark gray background)

2. UIRenderer.drawBases()
   ├─> 绘制敌方基地 🏰 (左侧，红色)
   ├─> 绘制玩家基地 🏰 (右侧，绿色)
   ├─> 绘制敌方基地血条
   └─> 绘制玩家基地血条

3. UIRenderer.drawCharacters()
   ├─> 绘制所有玩家角色
   │   ├─> 绘制角色emoji
   │   └─> 绘制角色血条 (蓝色)
   └─> 绘制所有敌人
       ├─> 绘制敌人emoji
       └─> 绘制敌人血条 (红色)

4. ResourceDisplay.drawMoney()
   └─> 顶部显示当前金钱 (黄色文字)

5. ResourceDisplay.drawBases()
   ├─> 显示敌方基地信息 (名称和HP)
   └─> 显示玩家基地信息 (名称和HP)

6. UIRenderer.drawButtons()
   └─> 底部绘制5个召唤按钮
       ├─> 🐱 猫战士 (50)
       ├─> 🐶 狗守卫 (75)
       ├─> 🦅 鹰弓手 (60)
       ├─> 🐢 龟坦克 (100)
       └─> 🐰 兔法师 (80)

7. ResourceDisplay.drawGameOver() (如果游戏结束)
   └─> 屏幕中央显示 "胜利!" 或 "失败!"

═══════════════════════════════════════════════════════════════════════════
                            玩家交互流程
═══════════════════════════════════════════════════════════════════════════

玩家点击屏幕
    │
    ▼
GameView.onTouchEvent()
    │
    ├─> 游戏结束了？
    │   └─> 是：重置游戏 (GameEngine.reset())
    │
    └─> 游戏进行中？
        └─> ButtonManager.handleTouch()
            │
            ├─> 检测点击位置是否在某个按钮上
            │
            └─> 在按钮上？
                └─> CharacterSpawner.spawnCharacter()
                    │
                    ├─> MoneyManager.canAfford()? 检查金钱是否足够
                    │
                    ├─> 足够：
                    │   ├─> 扣除金钱
                    │   ├─> 在玩家基地附近创建角色
                    │   └─> 添加到GameState.playerCharacters
                    │
                    └─> 不够：忽略点击

═══════════════════════════════════════════════════════════════════════════
                            战斗伤害计算
═══════════════════════════════════════════════════════════════════════════

攻击者攻击目标
    │
    ├─> 计算伤害: 实际伤害 = max(1, 攻击者攻击力 - 目标防御力)
    │
    └─> 目标受到伤害
        │
        ├─> 目标HP -= 实际伤害
        │
        └─> 目标HP ≤ 0?
            └─> 是：下一帧从列表中移除

═══════════════════════════════════════════════════════════════════════════
                            游戏胜负判定
═══════════════════════════════════════════════════════════════════════════

每帧检查:
    │
    ├─> 玩家基地HP ≤ 0?
    │   └─> 是：设置 isGameOver=true, playerWon=false
    │       显示"失败!"，等待玩家点击重新开始
    │
    └─> 敌方基地HP ≤ 0?
        └─> 是：设置 isGameOver=true, playerWon=true
            显示"胜利!"，等待玩家点击重新开始
